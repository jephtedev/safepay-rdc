## 🚀 La Vision
**SafePay RDC** brise la barrière de la méfiance dans le commerce numérique congolais. Grâce à un mécanisme de **Séquestre Intelligent**, nous garantissons que chaque transaction est protégée : l'argent ne change de main que lorsque le client confirme physiquement avoir reçu son produit.

---

## 🖥️ Simulateur Global (Tout-en-un)
Nous avons développé un environnement de démonstration unique. Il permet de visualiser en temps réel la synchronisation entre l'Acheteur, le Vendeur et l'Administration.

> **Explorez la démo live ici :** [https://jephtedev.github.io/safepay-rdc/](https://jephtedev.github.io/safepay-rdc/)

## 🏗️ Architecture Technique
Notre système repose sur une synchronisation fluide entre trois piliers :

| Rôle | Fonctionnalité | Technologie |
| :--- | :--- | :--- |
| **Acheteur** | Commande, Paiement Séquestre, Suivi | Tailwind CSS |
| **Vendeur** | Gestion stock, Validation livraison | API REST |
| **Admin** | Supervision, Audit, Litiges | Dashboard PC |



---

## 💎 Points Forts
* **Validation Hybride :** Confirmation de réception via **OTP** ou **QR Code dynamique**.
* **Zéro Risque :** Système de séquestre qui élimine les arnaques en ligne.
* **Tableau de Bord Exécutif :** Une console de contrôle centralisée pour les administrateurs.
* **Technologie Agile :** Déployé sur une infrastructure cloud évolutive (Render).
